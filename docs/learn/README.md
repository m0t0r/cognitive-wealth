# Learn

Primers on the wealth-management domain, written for an engineer who is new to finance. Each one explains a few ideas in plain words, with worked examples in real numbers, and lands before the code that depends on it.

Read them in this order:

1. [The ledger, Positions and the three dates](01-ledger-positions-and-dates.md): what a Custodian is, Transactions, why Positions are rebuilt from an append-only ledger, Trade date, Settlement date and As-of date, corrections, Market value and cash.

Every domain term a primer uses is defined in [GLOSSARY.md](../../GLOSSARY.md). The decisions behind the system, and their reasons, are the ADRs in [docs/adr/](../adr/). Where a primer and an ADR disagree, the ADR wins.
